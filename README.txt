HOW TO DEPLOY
1. Back up your current GitHub Pages repository.
2. Replace the current index.html with the new index.html.
3. Upload the entire assets folder beside index.html.
4. Commit changes to the branch used by GitHub Pages.
5. Open https://riyadussolihin.github.io and hard-refresh (Ctrl+F5).
